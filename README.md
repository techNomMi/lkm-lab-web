# ЛКМ — JavaScript + HTML/CSS

Интерактивная лабораторная работа № 2. Теория, модели H и C, SVG-схема установки, графики, шесть базовых экспериментов, собственные опыты, точная оптимизация, CSV и подготовка к защите.

## Запуск

Откройте `index.html` в современном браузере. Установка Python, Node.js или библиотек не требуется. После скачивания все расчёты и графики работают без интернета. На мобильном устройстве удобнее открывать опубликованный сайт. Кнопка «Параметры» открывает меню и поля ввода.

Для размещения на статическом хостинге загрузите файлы приложения, сохранив файлы рядом.

## Архитектура

- `index.html`: интерфейс и текст веб-отчёта.
- `styles.css`: оформление и адаптивные правила.
- `model.js`: самостоятельные математические функции.
- `app.js`: события, SVG-графики, таблицы, localStorage и экспорт.
- `test-model.cjs`: независимые проверки численного ядра (при наличии Node.js: `node test-model.cjs`).

Используется обычный JavaScript, без фреймворков и внешних зависимостей. Графики поддерживают указатель мыши и касание. Сохранённые режимы хранятся в текущем браузере, когда localStorage доступен; в остальных случаях — до закрытия страницы. Для переноса результатов между устройствами скачайте CSV.

## Математика

H=100(1−exp(−knt)); E=n²t. Ограничения: 100≤n≤500 об/мин, 1≤t≤20 мин. k в 1/оборот. V не входит в заданную формулу H и используется в модели C(t).

Оптимизация непрерывная: q=−ln(1−Hцель/100)/k, n*=max(100,q/20), t*=max(1,q/n*). Если q>10000, допустимого режима нет. Доказательство приведено в интерфейсе.

При k=0,001 и цели 95% оптимум: n=149,7866136777 об/мин, t=20 мин, H=95%, E=448720,5927406479 условных единиц. Округление настройки мешалки требует повторного расчёта качества.

Модель концентрации: T=V/(G₁+G₂), P=(G₁C₁+G₂C₂)/(G₁+G₂), C(t)=P+(C₀−P)exp(−t/T). Она описывает непрерывный идеальный смеситель постоянного объёма. Уточнения к ошибкам численных примеров методички включены в веб-отчёт.
